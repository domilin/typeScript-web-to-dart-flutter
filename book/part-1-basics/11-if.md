# 11｜if 语句：控制流 + 空安全的组合

这一章我会带你：把 TS 的条件分支与类型收窄经验迁移到 Dart：尤其是“空检查后变量被收窄”的行为。

## 我先把概念讲清楚

### 1) 基本形态

```dart
if (cond) {
} else if (other) {
} else {
}
```

### 2) 空检查与收窄

```dart
String? s;
if (s != null) {
  // 这里 s 被视为 String（非空）
  print(s.length);
}
```

这对位 TS 的：

```ts
let s: string | null = null;
if (s !== null) s.length;
```

## 然后我用对照例子讲

### 1) 三元运算（表达式）

TS：

```ts
const label = done ? "DONE" : "TODO";
```

Dart：

```dart
final label = done ? 'DONE' : 'TODO';
```

### 2) guard style：早返回

```dart
Widget build(BuildContext context) {
  final user = ref.watch(userProvider).valueOrNull;
  if (user == null) return const LoginPlaceholder();
  return ProfileView(user: user);
}
```

## 我在项目里怎么做（Flutter 条件渲染）

React 的常见写法：

```tsx
{user ? <Profile user={user} /> : <Login />}
```

Flutter 常见写法：

- 早返回（上面示例）
- 或在 `children: []` 内写 `if (...) ...`（见第 13 章）
